## 怎麼新增內容

### 新增一個化合物

打開 `assets/js/data/compounds.js`，在 `RAW` 陣列加一列：

```js
['NaClO3', '氯酸鈉', '', '強氧化劑，可作除草劑。'],
//  化學式    中文名   俗名   說明（後兩項可留空字串）
```

字典裡有的化合物會優先採用字典名稱；沒有的則會用規則自動命名，兩者不同時頁面會標示出來。

### 新增一個根離子

打開 `assets/js/data/ions.js`，在 `ANIONS` 加一列：

```js
{ key: 'BO3', zh: '硼酸', charge: -3, join: 'direct', acid: '硼酸' },
```

* `join: 'direct'` → 酸根，直接接金屬名（硫酸 + 鈉 = 硫酸鈉）
* `join: 'hua'` → 中間要加「化」（氫氧 + 化 + 鈉 = 氫氧化鈉）

### 修改元素資料

打開 `assets/js/data/elements.js`，格式是
`原子序|符號|中文名|族|週期|分類|原子量|常見價數`。

### 新增一個單元頁

1. 複製 `subjects/chemistry/formula.html` 當範本（頁首、頁尾、CSS 路徑都已寫好）。
2. 在 `index.html` 的對應科目區塊加一張 `<a class="unit">` 卡片。
3. 若不需要化學相關程式，把底部的 `<script>` 換成自己的。

## 改完東西學生卻看到舊版？

CSS 與 JS 的連結後面都帶了 `?v=20260917` 的版本號。瀏覽器（以及 GitHub Pages
的 10 分鐘快取）會依網址判斷要不要重抓，所以**改完樣式或程式後要把版本號換掉**，
不然回訪的學生會繼續看到舊版。在專案根目錄執行這一行就會全部換成今天的日期：

```sh
grep -rl '?v=' --include='*.html' . | xargs sed -i '' "s/?v=[0-9]\{8\}/?v=$(date +%Y%m%d)/g"
```

（Linux 的話 `sed -i` 後面不用加 `''`。）只改內容不改 CSS／JS 的話不用動它。

## 一元二次方程式單元

三個格子填 a、b、c，可以填整數（`-3`）、小數（`0.5`）或分數（`1/2`）；b、c 留白當作 0。
係數是分數時會自動乘上分母的最小公倍數化成整數，頁面上會標示「原式 → 整理後」。

網址一樣可以帶參數：`subjects/math/quadratic.html?a=1&b=-5&c=6`

### 台灣課本的三種解法

公式解、配方法、十字相乘法，每一步都寫出來。十字相乘只有在判別式是完全平方數時才出現，
不然會標示「這一題整數範圍內湊不出來」。

### 印度式（吠陀數學）的四種解法

| 招式 | 什麼時候好用 |
|---|---|
| 觀察法 Vilokanam | `a+b+c=0` → 一根是 1；`a−b+c=0` → 一根是 −1。看到就秒解 |
| 分裂中項法 | 把 b 拆成兩個數（相乘 = ac、相加 = b）再分組提公因式 — 印度課本的標準因式分解寫法 |
| 和差法 | 兩根之和 = −b/a、兩根之差 = √D/\|a\|，取平均得到兩根。驗算特別快 |
| 微分式法 Calana-kalana | 一次微分 `2ax+b = ±√D`，少寫一層分數 |

**這裡的定位要說清楚**：台灣講的「印度式數學」多半指 1965 年出版的《Vedic Mathematics》
整理的 16 條口訣，走的是心算捷徑路線；印度學校正式課本（NCERT）其實一樣教公式解與配方法。
所以頁面比的是「口訣捷徑 vs 台灣課本流程」，不是「印度課本 vs 台灣課本」，
頁面上也有一段話明講這件事，避免學生誤會。

### 延伸閱讀連結

## 命名規則涵蓋範圍

* **離子化合物**：陰離子 → 陽離子倒著念；變價金屬低價加「亞」（FeCl₂ 氯化亞鐵 / FeCl₃ 氯化鐵）
* **共價化合物**：把原子個數念出來（N₂O₅ 五氧化二氮）
* **酸**：含氧酸直接叫酸名（H₂SO₄ 硫酸）；不含氧的叫「X 化氫」
* **結晶水合物**：CuSO₄·5H₂O 五水合硫酸銅
* **單質**：氧化數 0

## 中國象棋單元

頁面分成五個分頁，是給完全沒下過棋的人設計的順序：

1. **認識棋子** — 七種棋子各一張示範盤，畫面會把牠當下所有能走的點標出來；另外五張示範盤專講最容易搞錯的規則（蹩馬腿、塞象眼、炮架、白臉將、應將）。
2. **學會記譜** — 拆解「炮二平五」四個字各代表什麼，棋盤可以自由擺弄，每走一步就寫出記譜；另附隨機出題的小測驗。
3. **殺法練習** — 走法題（馬走日、炮打隔子、過河卒）與殺法題（一步殺四題、兩步殺、三步殺）。多步殺的題目裡，**黑方會挑「撐最久」的應手**，而且你只要走出一步「之後就殺不掉」的棋，程式會立刻把棋子擺回去提醒你。
4. **打譜猜棋** — 五個開局定式加一盤示範對局，逐手講解；勾選「猜下一手」就變成由你走出棋譜裡的那一步。也可以把自己抄來的棋譜貼進去，讀不通會直接指出卡在第幾手。任何一個局面都可以按「從這裡接手」轉到對戰。
5. **跟電腦對戰** — 四種難度、可選執紅或執黑，附悔棋、提示、吃子清單與棋譜。

### 資料怎麼改

* **新增練習題**：編輯 `assets/js/data/xiangqi-lessons.js` 的 `drills`。局面用 `'k e9; a d9; C e5'` 這種寫法擺子 —— 大寫紅方、小寫黑方，直線 a\~i（紅方由左至右），橫線 0\~9（0 是紅方底線）。`type` 有三種：`mate`（幾步殺）、`reach`（走到某一格）、`capture`（吃掉某個子）。
* **新增棋譜**：編輯 `assets/js/data/xiangqi-games.js`，`moves` 直接寫中文記譜（回合編號、全形半形數字都可以），`notes` 的鍵是第幾手。
* **棋子的中文字、示範盤**：同樣在 `xiangqi-lessons.js` 裡，`setup` 與 `focus` 兩個欄位決定示範盤長什麼樣、要標出哪一種棋子的走法。

### 這些內容是怎麼驗證的

* 走法產生器跑過**四層 perft**，和公開的象棋標準值完全相符（44 / 1920 / 79666 / 3290240）—— 這一組數字同時驗到了蹩馬腿、塞象眼、炮架、九宮、河界與白臉將。
* 記譜模組做過**一萬七千多步的「寫成中文 → 讀回來」來回測試**，沒有一步出錯，也沒有出現兩步棋寫成同一組字的情形。
* 每一道殺法練習題都用殺棋搜尋器確認過：**局面合法**（輪走前對方沒有被將軍）、**強制殺棋剛好是宣稱的步數**，而且一步殺的四題都只有唯一解。
* 五個開局定式與示範對局都逐手經過規則引擎驗證，走不出來的棋根本存不進資料檔。

## 已知限制

* 有機化合物（葡萄糖、乙醇等）沒有系統性命名規則，靠字典收錄。
* 同一元素在化合物中有多種價態時（如 Fe₃O₄），表格顯示的是平均氧化數，頁面會另外提示。
* 過氧化物的氧為 −1 而非 −2，程式能算對（H₂O₂），但推導說明中會另外註明這是通則的例外。
* 一元二次方程式只處理實數解；判別式為負時只說明「沒有實數解」，不談複數（高中範圍）。
* 十字相乘與分裂中項只在整數範圍內找，找不到就標示用不了，不會硬湊分數。
* 象棋的勝負只判**將死、困斃、六十回合無吃子和局**三種。比賽規則裡的**長將判負、長捉判負**沒有實作（電腦有加分數懲罰避免原地兜圈子，但不會被判輸）。
* 象棋的電腦對手沒有開局庫，每一步都是現算的，所以低難度的開局有時會走得比較奇怪。
* 記譜法的「前／後」在同一方有四個以上同類棋子擠在同一條線上時（幾乎只會發生在兵），寫法可能和某些棋譜書的慣例不同；頁面自己產生與讀取的棋譜一定是一致的。
