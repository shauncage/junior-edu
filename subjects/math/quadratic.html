一元二次方程式

填入 a、b、c 三個係數，立刻看到解、判別式、頂點與圖形，還有台灣課本的三種解法與印度式（吠陀數學）的四種解法並排比較 — 同一題，看兩種文化怎麼教。

延伸閱讀：花拉子米（al-Khwārizmī）↗　九世紀在巴格達寫下第一本系統解方程式的書，書名裡的 al-jabr（移項還原）後來變成 algebra，他的名字則變成 algorithm。下面的配方法，就是他當年用幾何圖形證明的那一招。

改動任一個格子就會即時重算。可以填整數、小數（0.5）或分數（1/2）；b、c 留白當作 0。試試這些：

判別式在講什麼

判別式 D = b² − 4ac 就是公式解裡根號底下那一塊，它決定了拋物線和 x 軸的關係。

D > 0

根號開得出來而且不是 0，± 之後得到兩個不同的答案。
圖形穿過 x 軸兩次。
例：x² − 5x + 6 = 0，D = 1。

D = 0

± 0 之後兩個答案變成同一個，叫做重根。
圖形剛好碰到 x 軸一點（頂點就在 x 軸上）。
例：x² − 4x + 4 = 0，D = 0。

D < 0

負數開不出實數平方根 → 沒有實數解。
圖形整條在 x 軸的同一側，碰不到。
例：x² + 2x + 5 = 0，D = −16。

吠陀數學的口訣從哪來

「印度式數學」在台灣通常指 Vedic Mathematics（吠陀數學），是印度學者 Bharati Krishna Tirtha 整理、1965 年出版的一套心算方法，核心是 16 條梵文口訣（sūtra），例如「Vilokanam（由觀察）」、「Calana-kalana（連續變化）」。它強調先看數字的模式，再決定怎麼算，很多題目可以一行寫完。

  • 它是心算技巧的集合，不是印度學校的正式課本。印度課本（NCERT）一樣教公式解與配方法。
  • 真正和台灣課本明顯不同的，是因式分解：印度習慣寫成分裂中項（把 b 拆成兩個數再分組提公因式），台灣用十字相乘的交叉圖。兩者湊的是同一組數字，只是呈現方式不同。
  • 吠陀口訣的價值在速度與檢查：選擇題、估算、驗算特別好用；需要完整寫出過程的計算題，還是回到公式解最穩。
  • 學校教學上最實用的兩條：a + b + c = 0 → 必有一根是 1、a − b + c = 0 → 必有一根是 −1。看到就先試，省下整套公式解。
